# AI provenance

Astral's native Rust rebuild, new tools, fixes, tests and documentation were developed with AI coding agents under nqtexd's direction. This repository is openly labeled as AI-built/AI-assisted. It derives from GPL StykAnimate; original authors keep their attribution and rights. This disclosure does not claim all upstream code was generated by AI.

The app's small pose-completion model is separate from the coding agents used during development. Its synthetic training provenance, measurements and limits are described in [the model card](models/MODEL_CARD.md). Example-based motion and drawing learners use authored examples. No paid generation service or general text-to-video model is embedded.

An external MCP agent may use its own model/service. Account requirements, costs and handling of prompts/media depend on that client. Manual editing and local tools need no model account.

Human review remains necessary for security, licensing, usability and animation quality. Suggestions stay editable; geometric checks do not establish artistic quality. Report reproducible problems through GitHub issues.


The 0.14 voice-provider adapters, migration helper, deformation/brush extensions, shortcut editor and Spanish/French core-control catalogs were implemented with AI coding assistance. Provider contracts were checked against primary documentation. No proprietary Moho implementation or content was copied; the existing GPL source evaluator is retained as a transitional, read-only import helper. Feature equivalence and artistic quality are not inferred from generated code or passing tests.

The 0.15 compositing, PSD adapter, native AVI muxing, speech timing integration, brush controls and production-gate tooling were developed with AI coding assistance. Third-party parser/recognizer/runtime code and speech models remain separately attributed; Astral does not claim to have trained Rhubarb’s recognizers.
