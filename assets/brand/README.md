# Astral identity

The current mark is a simple A monogram on a graphite tile, matching the native editor's neutral surfaces and restrained blue controls. It replaces the earlier star/orbit decoration.

- astral-mark.svg: vector mark master.
- astral-mark-mono.svg: single-color vector mark.
- astral-wordmark.svg: mark and wordmark; Noto Sans text can be outlined by downstream design tools.
- astral.png and astral.ico: generated native icon assets.
- preview.svg: vector wordmark preview.

Run python scripts/build-astral-brand.py with Pillow installed to regenerate icons from the same geometric coordinates. Noto Sans is licensed under the OFL; packaged notices include its license. Legacy Inter font notices are retained.
