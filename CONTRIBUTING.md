# Contributing

Build the Rust app with locked dependencies and run the checks in README.md. Keep edits shared between GUI, CLI and MCP, revision-checked and undoable. Preserve legacy data/attribution and avoid silently rewriting users' animation.

For bugs, provide a small reproducible project, expected/actual behavior, version, OS/GPU, canvas/FPS and frame range. Include job metrics for performance reports. Remove personal or unlicensed media before uploading.

Add meaningful regressions for reproduced data-loss, timing, export and protocol bugs. Review moving previews as well as still images. A compile or geometric check is not proof of production-quality animation.

Follow GPL-3.0-or-later, retain third-party notices and disclose AI assistance when applicable. Do not commit credentials, private productions, caches or release archives.
